# RPIBusybox
Scripts para armar un sistema mínimo para RPI con Busybox/GCC/GLibc/Binutils

Estos scripts deben correr en Ubuntu 24.04 (amd64). No hay ninguna garantia de que funcionen con otra version (ej: ARM)

Sin necesidad de compilar, se puede descargar desde: https://drive.google.com/file/d/1z2KpWB5rwNZ3gaj_pUAjS2122J08LwOd/view?usp=sharing
